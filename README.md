# Joinery

细木作：与项目无关的 Unreal 编辑器便利工具箱。插件只依赖引擎模块与引擎自带的 HairStrands 插件，不引用任何项目资产。

工具入口都在关卡编辑器主菜单栏的 **Joinery** 菜单里。

## 模块

| 模块 | 作用 |
|---|---|
| `JoineryCore` | 公共模块：共用图标与样式集、主菜单栏上的 Joinery 菜单 |
| `JoinerySkeletalRefit` | Skeletal Refit：把蒙在任意人形骨架上的网格重新绑定到目标骨架 |

新增工具时一个工具一个模块，依赖 `JoineryCore`，把入口加进 `JNCoreConstants::JoineryMenuName`。

## Skeletal Refit

把蒙在来源骨架 B 上的骨骼网格重新绑定到目标骨架 A，转换后的网格直接使用 A 的动画，不再需要运行时重定向。A 上没有的骨骼追加进 A。

转换只重建骨骼层级、重算绑定并转移权重，顶点与变形目标不动。来源网格不会被修改，导出结果是一个新的网格资产。

### 使用步骤

1. 打开 Joinery > Skeletal Refit。
2. `Target Skeleton` 选目标骨架 A。
3. `Meshes` 加入要转换的网格，第一个放身体。只放身体就只导出身体；把头也放进来，头会并进同一个网格。
4. `Bones` 会按自动规则填好。检查并修改需要特殊处理的行。
5. 右边的视口会自动显示转换结果，改了设置后自动刷新；`Preview Animation` 选了动画就循环播放。
6. 点 Export。列表里的网格合成一个带后缀的新网格，结果与提示显示在窗口左下方。
7. 检查无误后保存新网格与目标骨架。

窗口里的设置不存盘，关掉窗口后手改的行会丢。

### 设置

| 字段 | 含义 |
|---|---|
| Target Skeleton | 目标骨架 A |
| Meshes | 要转换的网格，导出时合成一个；第一个是底 |
| Append Prefix | 追加骨骼的名字前缀，避免不同角色的私有骨骼重名 |
| Excluded Target Bones | 不带进新网格的目标骨骼（连同子骨骼）；被对应到的骨骼及其祖先不受影响 |
| Bones | 来源骨骼的处理方式，一根一行 |
| Copy Skeleton Sockets | 把来源骨架上的插槽复制成新网格自己的插槽 |
| Rebuild Groom Bindings | 导出时为新网格重建毛发 Binding |
| Output Folder | 新网格所在的内容目录，留空时与来源网格同目录 |
| Output Suffix | 新网格名在来源网格名后追加的后缀 |
| Preview Animation | 预览时播放的动画，要用目标骨架上的动画 |
| Show Bones | 预览视口里是否叠画骨骼连线 |

### 骨骼处理方式

| 处理方式 | 含义 | Target Bone 填什么 |
|---|---|---|
| Map | 对应到 A 上的一根骨骼，权重转给它 | A 上的骨骼名 |
| Append | A 上没有，追加为新骨骼，保持原位置与朝向 | 父骨骼名；留空取最近的保留祖先 |
| Merge | 不保留，权重并入另一根骨骼 | 并入的骨骼名；留空取最近的保留祖先 |
| Discard | 不保留；万一带权重，落到最近的保留祖先并给出警告 | 不填 |

自动规则：A 上有同名骨骼则 Map，否则带权重的 Append、不带权重的 Discard。

- 换了 `Target Skeleton`，`Bones` 整表按自动规则重建。
- 改了 `Meshes`，只补上还没有列出的骨骼，已有的行不动。
- `Reset Bones` 按钮按自动规则整表重建，丢掉手改的行。

### 预览

视口按当前设置临时转换列表里的所有网格并显示，不产生资产，也不修改目标骨架。目标骨架、网格、骨骼处理表等会改变结果的设置一改就自动重做；换动画和开关骨骼显示不重做。Preview 按钮用来手动重做一次。

- 预览与导出用同一个方案：列表里的网格合成一个显示。
- 骨骼连线画的是合并后网格的全部骨骼。
- 预览用的是目标骨架的一份临时副本，追加的骨骼只写进这份副本。

### 多个网格合成一个

`Meshes` 表示一个角色的各个部分，导出时永远只生成一个网格。

- 只放身体：只导出身体。头仍是独立的网格，之后还可以单独更换。
- 身体和头都放：头并进身体，得到一个网格，之后不能单独换头。

第一个网格是底，新网格的名字、默认输出目录、布料与物理资产都跟它。其余网格按下面的方式并入：

| 数据 | 处理 |
|---|---|
| 骨骼 | 各自按骨骼处理表转换，多出来的骨骼补进底的骨骼层级 |
| 几何与蒙皮权重 | 追加在底的后面，权重换成合并后的骨骼 |
| 材质槽 | 追加在底的材质后面；槽名与已有的重复时接上并入网格的名字 |
| 变形目标 | 位移数据随顶点带过来；法线由引擎重算 |
| 插槽 | 复制过来，同名的不覆盖 |
| 毛发 Binding | 每个来源网格上的 Binding 都改绑到导出的网格 |
| 布料 | 只保留底的布料；其余网格上的布料会丢失并给出提示 |
| LOD | 并入网格缺少某一级的源几何时，那一级没有它并给出提示 |

### 转换规则

- **有对应的骨骼**：位置取网格原来的关节位置，保留角色自己的体型；朝向取目标骨架的规范，并对齐到网格的肢体方向，所以来源是 T 姿态还是 A 姿态都可以。
- **目标骨架有、来源没有对应的骨骼**：按目标骨架上相对父骨骼的位置补上，不带权重。
- **追加的骨骼**：保持原来的位置与朝向，写进目标骨架资产。
- **权重**：按处理方式转移，并入的相加，总和不变。

### 随网格一起处理的附属数据

| 数据 | 处理 |
|---|---|
| 布料（Chaos Cloth） | 布料数据内嵌在网格里，随网格带过来。它记录的骨骼名按骨骼处理表更新，骨骼下标按新层级重建 |
| 布料的碰撞物理资产 | 用到的骨骼在新网格里都在就沿用，否则清掉并给出警告 |
| 物理资产 | 用到的骨骼在新网格里都在就沿用，否则清掉并给出警告 |
| 后处理动画蓝图 | 本来就是目标骨架的才保留，否则清掉并给出警告 |
| 网格自己的插槽 | 保留。所挂的骨骼换成新名字，相对位置重算，在模型空间里的位置不变 |
| 来源骨架上的插槽 | `Copy Skeleton Sockets` 打开时复制成新网格自己的插槽，位置不变 |
| 毛发 Binding | `Rebuild Groom Bindings` 打开时，导出后为指向来源网格的 Binding 各建一份指向新网格的副本并重建 |

- 物理资产与布料碰撞按骨骼名匹配。追加骨骼加了前缀就会对不上，想沿用原资产时 `Append Prefix` 留空。
- 插槽与骨骼重名时，引擎按名字查找先取插槽，结果里会给出提示。
- 毛发 Binding 的重建是异步的，导出后需要等它完成再保存。

### 导出后需要人工处理的

- 被清掉的物理资产、后处理动画蓝图，需要为新网格重新制作或指定。
- 骨骼驱动的裙摆、披风靠"物理资产 + 后处理动画蓝图"一起驱动，两者缺一个骨骼都不会动。
- 用到来源网格的角色蓝图、预览配置等，需要手动换成新网格与新的毛发 Binding。
- 工具不改变体型。角色比例与目标骨架差得多时，手脚的接触点会偏，需要靠 IK 补。
- 骨骼驱动的面部（面部骨骼很多）不建议并进目标骨架：头保留自己的骨架作为独立部件，只对应与身体共用的骨骼。

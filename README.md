# Joinery

细木作：与项目无关的 Unreal 编辑器便利工具箱。插件只依赖引擎模块，不引用任何项目资产。

工具入口都在关卡编辑器主菜单栏的 **Joinery** 菜单里。

## 模块

| 模块 | 作用 |
|---|---|
| `JoineryWorkbench` | 公共模块：共用图标与样式集、主菜单栏上的 Joinery 菜单 |
| `JoinerySkeletalRefit` | Skeletal Refit：把蒙在任意人形骨架上的网格重新绑定到目标骨架 |

新增工具时一个工具一个模块，依赖 `JoineryWorkbench`，把入口加进 `JNWorkbenchConstants::JoineryMenuName`。

## Skeletal Refit

把蒙在来源骨架 B 上的骨骼网格重新绑定到目标骨架 A，转换后的网格直接使用 A 的动画，不再需要运行时重定向。A 上没有的骨骼追加进 A。

转换只重建骨骼层级、重算绑定并转移权重，顶点与变形目标不动。来源网格不会被修改，转换结果是一个新的网格资产。

### 对应表（Skeletal Refit Jig）

内容浏览器里新建：Joinery 分类下的 Skeletal Refit Jig。一种来源骨架配一份，同来源的网格反复使用。

| 字段 | 含义 |
|---|---|
| Target Skeleton | 目标骨架 A |
| Append Prefix | 追加骨骼的名字前缀，避免不同角色的私有骨骼重名 |
| Excluded Target Bones | 不带进新网格的目标骨骼（连同子骨骼）；被对应到的骨骼及其祖先不受影响 |
| Bones | 来源骨骼的处理方式，一根一行 |

每根来源骨骼的处理方式：

| 处理方式 | 含义 | Target Bone 填什么 |
|---|---|---|
| Map | 对应到 A 上的一根骨骼，权重转给它 | A 上的骨骼名 |
| Append | A 上没有，追加为新骨骼，保持原位置与朝向 | 父骨骼名；留空取最近的保留祖先 |
| Merge | 不保留，权重并入另一根骨骼 | 并入的骨骼名；留空取最近的保留祖先 |
| Discard | 不保留；万一带权重，落到最近的保留祖先并给出警告 | 不填 |

没有列在表里的来源骨骼按自动规则处理：A 上有同名骨骼则 Map，否则带权重的 Append、不带权重的 Discard。

### 使用步骤

1. 新建一份 Skeletal Refit Jig，填 Target Skeleton。
2. 打开 Joinery > Skeletal Refit，选这份 Jig，把要转换的网格加进 Meshes。共用骨骼的网格（比如身体与头）放在一起转换。
3. 点 Auto Fill Jig，按同名自动填表；然后在 Jig 资产里检查并修改对不上的行。
4. 点 Refit。每个网格生成一个带后缀的新网格，结果与警告显示在窗口下方。
5. 检查无误后保存新网格与目标骨架。

### 转换规则

- **有对应的骨骼**：位置取网格原来的关节位置，保留角色自己的体型；朝向取目标骨架的规范，并对齐到网格的肢体方向，所以来源是 T 姿态还是 A 姿态都可以。
- **目标骨架有、来源没有对应的骨骼**：按目标骨架上相对父骨骼的位置补上，不带权重。
- **追加的骨骼**：保持原来的位置与朝向，写进目标骨架资产。
- **权重**：按处理方式转移，并入的相加，总和不变。

### 转换后需要人工处理的

- 物理资产与后处理动画蓝图是按来源骨架做的，转换时会清掉，需要为新网格重新指定。
- 毛发 Binding 需要对新网格重做。
- 来源**骨架**上的插槽不会带过来；网格自己的插槽会跟着骨骼改名。
- 工具不改变体型。角色比例与目标骨架差得多时，手脚的接触点会偏，需要靠 IK 补。
- 骨骼驱动的面部（面部骨骼很多）不建议并进目标骨架：头保留自己的骨架作为独立部件，对应表里只对应与身体共用的骨骼。
